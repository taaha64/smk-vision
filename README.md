# SMK Vision

Chrome extension that screenshots the question on your screen, sends it to the AI vision
models you configured with your own API keys, and shows the answer in a panel on the page.

- **[Privacy policy](https://taaha64.github.io/smk-vision/)** — what is stored, what is sent, and why each permission is needed
- **[Chrome Web Store listing copy](listing.md)** — description and permission justifications

No server, no account, no analytics. API keys stay in your own browser and are sent only
to the service they belong to.
